# SMP Blockchain Analytics

A professional blockchain intelligence landing dashboard built with Next.js and optimized for deployment on Netlify.

## Features

- Modern dark UI for blockchain data products
- Multi-chain market and network overview
- Wallet and transaction insights sections
- Netlify-ready configuration
- No login required for the initial version

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Netlify

1. Push this repository to GitHub.
2. Import the repo in Netlify.
3. Use the default Next.js settings or the included `netlify.toml`.
4. Add a custom domain from Netlify when ready.

## Notes

This project is intentionally designed as a polished MVP landing dashboard for the blockchain analytics platform. It can be expanded later with wallet search, charts, and live blockchain API integrations.
